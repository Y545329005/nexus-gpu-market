## 四、可选加场（时间富余时，每项 ≤1 min）

- **封禁**：Tab B「用户与合规」封禁 alice@demo.dev → Tab A 被登出，重登被拦「该账号已被封禁」→ Tab B 解封 → 登录成功。
- **异常状态机**：Tab A 底部 Demo 控制条触发「宿主断连→Offline / 快进到期→Expired」。
- **多语言**：Header 右上 pill 切 EN，全页无缺键。

## 五、已知边界与救场预案（照读不修）

| 风险 | 预案 |
|---|---|
| 出金批准未实时亮灯（单 tab 或广播丢失） | 确认双 tab 都开着；刷新 Tab A——配置类干预挂载重放，批准效果补生效（幂等不重复扣） |
| 注入把现场搞乱 | Tab B「还原快照」一键回滚（建议先关 Tab A 再还原） |
| 断网 / CDN 被劫持 | 顶部红色降级横幅属已知边界；切手机热点 |
| 「收益明细」看不到流水 | 明细仅展示 ledger 窗口内近期流水（42 条上限），以顶卡累计数字为准（口径准确） |
| 审批账本残留旧申请 | Tab B「重置 Admin 配置」清空后重走第 4 幕 |
